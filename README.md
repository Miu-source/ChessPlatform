# ChessPlatform ♟️

A multiplayer chess platform built with HTML, CSS, JavaScript and using Supabase.

## Features

- User registration and authentication
- Player profiles
- Username editing and validation
- Rating and statistics display
- Dashboard navigation
- Dark interface with muted green accents

## Technologies

- HTML5
- CSS3
- JavaScript
- Supabase
- GitHub Pages

## Hosting

The website is hosted using GitHub Pages.

## Development Status

Currently in development.

Planned features include:
- Complete chess system
- Local multiplayer
- Chess clocks
- Online multiplayer
- Playing against bots
- Elo rating system
- Spectators and leaderboards
